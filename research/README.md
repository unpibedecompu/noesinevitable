# Research

Carpeta para registrar investigación de producto/growth sobre este sitio:
lecturas de analytics, hipótesis, experimentos y sus resultados. No es
documentación de arquitectura (eso vive en `PROJECT_SPEC.md` /
`PROJECT_ESSENCE.md` / `PROJECT_STATUS.md`) — es el historial de *por qué*
se tomó tal decisión de producto, con la data que la motivó.

Convención: una carpeta por fecha/tema (`YYYY-MM-DD-tema/`) con un
`.md` de análisis y, si aplica, capturas de pantalla como evidencia.
